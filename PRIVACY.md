# Privacy

Offline LAN Games Helper for macOS works locally. It may read bundled game data, selected settings, and invite fields typed by the user. It does not upload telemetry, game detection results, or invite text.

Donation links open only when clicked.

## Local Loading Cache

The macOS version may cache selected game details in memory while the app is open so repeated selections are faster. This cache stays on the Mac and is cleared when the app closes.
